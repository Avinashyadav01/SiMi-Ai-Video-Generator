# Local background-video library

Put background videos here that you own or are licensed to use. SiMi searches these folders using the AI-generated visual keywords:

```text
data/assets/
  productivity/
    focused_work.mp4
  sunrise/
    morning_city.mp4
  fallback/
    abstract_background.mp4
```

Use common video formats such as MP4. Folder and file names should describe the footage (for example `coding/`, `students/`, or `nature/`). The `fallback/` folder is only used when no keyword-matched clip is available. Keep proof of licenses for the footage you add.

The app does not fetch footage from random websites. When it cannot find a local suitable video, it marks that job failed and explains how to add an asset.
